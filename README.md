# Odo

Your yearly Strava goals in the Mac menu bar.

**[Download Odo](https://github.com/bymayo/odo-releases/releases/latest)** · [odo.bymayo.co.uk](https://odo.bymayo.co.uk)

Free · macOS 13 or later · Signed and notarised by Apple

Odo updates itself. This repository holds the releases and `appcast.xml`, the update feed the app checks, both published automatically.
